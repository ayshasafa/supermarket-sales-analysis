# Supermarket Sales Analysis

## Project Overview
This project analyses supermarket sales data using Python, pandas, and SQL to identify sales trends, product performance, and customer payment methods.

## Technologies Used
- Python
- pandas
- SQL and SQLite
- Matplotlib
- Power BI (dashboard in progress)

## Project Analysis
- Total sales revenue: 18,895 NOK
- Highest revenue product: Coffee (3,225 NOK)
- Total quantity sold: 524 units
- Monthly sales analysis
- Product and category performance
- Payment method analysis

## Project Files
- sales_analysis.py — Python analysis
- supermarket_analysis.sql — SQL queries
- supermarket_sales.csv — Sales dataset
- supermarket.db — SQLite database
- PNG files — Sales charts
- Supermarket_Sales_Analysis.pbix — Power BI work in progress
